FAQ

常见问题

需要管理员权限？

是。全局热键与游戏目录读取需要提权，首次运行 Windows 会弹 UAC 确认。

会被封号吗？

工具只读取本地日志与截图文件名，不注入、不修改游戏进程，不联网。请勿用于雷达等作弊用途——那是明确禁止的。

支持哪些地图？

13 张：中心区、海关、工厂、森林、立交桥、海岸线、储备站、实验室、灯塔、街区、迷宫、码头、破冰船。

怎么卸载？

删掉解压目录即可，干净无残留；进度保存在 %APPDATA%\TarkovAtlas，一并删除即完全清除。
