Tarkov Atlas 首个公开发布。Windows x64 原生构建（NativeAOT，免安装 .NET 运行时）。

**下载后解压整个目录**，运行 `TarkovAtlas-win-x64/TarkovAtlas.exe`（需随附同目录的 DLL 与 `Assets/`，约 263 MB）。首次运行会请求管理员权限（全局热键所需）。

## 本版本包含

- 13 张离线高清底图（上北下南）+ 52 个楼层条目 + 雷区/狙击区危险层
- 撤离点 / Boss 刷点 / 出生点 / 转移点 / BTR / 物资与埋藏点 / 解谜道具全套标记，逐项可开关
- 离线任务库 468 条（官方中文名，已剔除eftarkov.com 复核确认下线的任务）+ 10 章剧情进度 + 255 个任务的地点攻略图
- 任务搜索支持中文（含「- 2」等紧凑写法）；OCR 截图识别坐标与朝向，悬浮窗跟随定位
- 无边框悬浮小窗：置顶、左键拖图、右键拖窗、滚轮光标锚缩放

完全离线：运行时不请求任何网络；「打开 Wiki」只是用系统浏览器打开网页。
